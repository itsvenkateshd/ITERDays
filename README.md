# ITERDays

Welcome to **ITERDays**, an academic resource hub created for the students and academic community of **ITER, SOA University, Bhubaneswar**.

Created and maintained by **Venkatesh D.**, Assistant Professor, Department of Computer Science and Engineering, this repository provides a centralized collection of **source codes, assignments, notes, and practical resources** to support classroom learning and hands-on practice.

## 📚 Repository Contents

### ☕ Java Programming (ICP)

* Source codes from classroom and laboratory sessions
* Practical programming examples
* Lab assignments with solutions
* Practice problems for strengthening Java fundamentals

### 🔗 Data Structures & Algorithms

* Java implementations of fundamental data structures and algorithms
* Source codes from classroom and laboratory sessions
* Practical assignments with solutions
* Problem-solving resources for hands-on practice

### 💡 Introduction to Problem Solving

* Java-based programming examples
* Problem-solving exercises
* Practical programs and coding practice
* Resources to build programming fundamentals

## 🎯 Purpose

ITERDays aims to provide students with an **organized and accessible learning resource** that connects classroom concepts with practical programming.

The repository is intended to support:

* **Conceptual learning**
* **Practical implementation**
* **Regular coding practice**
* **Assignment preparation**
* **Revision and reference**

> **Learn the concept. Write the code. Practice the problem. Build the skill.**

---

**ITERDays** is an ongoing effort to build a structured academic ecosystem where students can easily access course resources and develop strong programming and problem-solving skills.
